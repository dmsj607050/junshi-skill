# 军师，速来相助

一个帮你看懂暧昧、约会、恋爱和分手的对话 Skill。说话像愿意站在你这边的朋友：听懂你为什么难受，也敢按事实给判断，不替你猜心。

## 这个仓库怎么组织

这是一个 Skill 加一套独立评测材料，不是把同一人格拆成几份互相抢话的 Skill：

- `skills/junshi/`：可单独安装的 Skill 包。
- `skills/junshi/references/`：按需读取的判断、情绪支持、多轮对话和安全模块。
- `evals/`：50 个多轮对话题目、评分标准和三轮迭代记录；这些评测材料不属于安装包。

## 能帮什么

- 看关系有没有实际进展，区分好感和稳定投入
- 复盘冲突、承诺、道歉、信任和边界
- 判断要不要继续、复合或减少联系
- 准备清楚自然的沟通话术
- 在用户只需要安慰时先陪伴；出现安全风险时优先处理安全

## 判断方式

军师先抓故事里最让人卡住的具体落差，再给有依据的立场。可以说“别替他找借口了”，但不把未证实的动机说成事实，也不靠羞辱用户来装亲近。用户已经问过、邀约过或道过歉，就不会机械地让用户再做一次。

## 使用

在支持 Skills 的环境中安装 `skills/junshi/` 里的 Skill 包。安装后可以直接描述情况，也可以显式调用 `@junshi`。

## 评测

`evals/prompts.md` 收录 50 个对话案例，每例两轮，共 100 个回复点；`evals/scorecard.md` 用于人工检查共情、判断、事实边界、下一步和口语自然度；`evals/iteration-log.md` 记录按失败案例所做的修改及回归结果。

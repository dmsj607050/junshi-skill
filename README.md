# 军师（Junshi）

一个帮你看清暧昧、约会和亲密关系的对话 Skill。它像一个愿意站在你这边、也肯说实话的朋友：先听懂你为什么卡住，再根据你说的事实给判断和下一步。

它不替你猜心，也不为了“客观”把明显失衡的行为说成各有道理。

## 能帮你看什么

- 对方的言行是不是前后矛盾，关系有没有实际往前走
- 这段关系值不值得继续投入，还是该先把精力收回来
- 聊天里的撒谎、越界、敷衍或反复爽约
- 怎么开口表达需求、设边界，或结束一段关系

## 判断原则

- 看具体行为和时间线，不把零星的热情当成持续投入。
- 把“可能有好感”和“愿意认真行动”分开看。
- 认真回应用户的失望、委屈和自责，但不把没有证据的猜测说成事实。
- 结论该明确时就明确；不知道对方动机时，也会把未知讲清楚。
- 用户已经表达过或邀约过，就不机械地让用户再追问一次。
- 遇到威胁、控制、胁迫或暴力，优先考虑现实安全。

## 使用方式

在支持 Skills 的环境中安装本 Skill。安装后可以直接描述你的情况，也可以显式调用 @junshi。

提供具体细节会更有帮助，例如：认识多久、发生了什么、你已经说过或做过什么，以及你现在最想决定什么。只知道一条模糊消息时，军师会承认信息不足，不会硬编一个故事。

```text

```

## 适用范围

军师提供的是基于你所述信息的关系判断和沟通建议，不是心理诊断，也不能替代紧急情况下的现实支持。
